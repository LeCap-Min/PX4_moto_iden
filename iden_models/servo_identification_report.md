# FashionStar 总线舵机闭环辨识报告

**对象**：两台 FashionStar UART 总线舵机，代号 alpha（总线 ID 1 / 3）与 beta（总线 ID 5 / 7）
**辨识量**：指令角 $\to$ 总线回传角的**闭环**传递函数（舵机内部位置环已闭合，对飞控而言这是被控对象）
**平台**：PX4 (CUAV V5 Nano / px4_fmu-v5)，台架辨识专用固件，`IDEN_TYPE=3`
**数据**：2026-08-27，共 14 份 ulog
**用途**：100 Hz 外环控制算法仿真

## 二、实验设置

### 2.1 固件与参数

`IDEN_TYPE=3` 时 `control_allocator` 自动启动 `fs_uart_servo` 驱动，扫频期间自动开启目标舵机的角度回传。

| 参数 | 取值 | 说明 |
|---|---|---|
| `IDEN_TYPE` | 3 | 总线舵机扫频 |
| `IDEN_SV_IDX` | 1 / 3（alpha），5 / 7（beta） | 舵机总线 ID |
| `IDEN_SV_HZ` | **100** | 命令与查询同频；主数据集均为 100 Hz |
| `IDEN_CH_F0` / `F1` | 0.2 / 30（log6 为 60） | 扫频上下限 Hz |
| `IDEN_CH_DUR` | 90 | 单次对数扫频时长 s |
| `IDEN_CH_AMP` / `AMIN` | 8 / 1.5 | 低频幅值 / 最小幅值，单位度 |
| `IDEN_CH_STEP` | 15 | 速率自测阶跃幅值 度 |
| `IDEN_CH_REP` / `HALF` | 3 / 1 | 全幅重复 3 次 + 半幅 1 次 |
| `FS_UT_1WIRE` | 1 | TELEM2 TX 单线半双工 |
| `FS_UT_BAUD` | 1000000 | 1 Mbaud |
| `FS_UT_INTV` | 0 | FashionStar 极速同步指令 |

### 2.2 扫频时序

一次 AUX1 触发自动跑完：

1. 静置 1 s（0°）
2. 速率自测约 4 s：$0 \to +S \to -S \to 0$，估计 $V_{\max}$
3. 引导：$f_0$ 恒频 2 个整周期
4. 对数扫频 $f_0 \to f_{1,\mathrm{use}}$，时长 `IDEN_CH_DUR`，重复 3 次（段间停 2 s）
5. 半幅扫频 1 次（线性性检验）

总时长约 7 分钟。

### 2.3 幅值自适应

为避免撞上速率限制，扫频幅值随频率衰减（速率裕度 $k=0.6$ 写死）：

$$
A(f)=\mathrm{clamp}\!\left(\frac{k\,V_{\max}}{2\pi f},\;A_{\min},\;A_0\right),\qquad
f_{1,\mathrm{eff}}=\frac{k\,V_{\max}}{2\pi A_{\min}},\qquad
f_{1,\mathrm{use}}=\min(F_1,\,f_{1,\mathrm{eff}})
$$

实测幅值示例（log6，$V_{\max}=596$ °/s）：10 Hz 时 5.69°，20 Hz 时 2.85°，30 Hz 时 1.90°，38 Hz 触底 1.50°。

### 2.4 $V_{\max}$ 来源（`fb_source`）

- `fb_source=1`：陀螺峰值。仅当阶跃时陀螺峰值 $>30$ °/s，即判定 IMU 装在舵臂上
- `fb_source=2`：总线回传角三点斜率
- `fb_source=0`：都没有，退化为固定幅值扫到 `IDEN_CH_F1`

> **坑**：飞控**不在**舵臂上时，阶跃引起的机架抖动可能产生 40 °/s 的尖峰，被误判为 `fb_source=1`，得到错误的小 $V_{\max}$，把扫频上限压得极低。log1 即因此只扫到 2.56 Hz 而作废。

## 三、数据处理方法

### 3.1 频响估计

对每一次全幅扫频，按对数频段分箱（29 或 35 个几何等分频段），每段内用瞬时相位做最小二乘投影：

$$
\phi(t)=\int_0^t 2\pi f(\tau)\,\mathrm{d}\tau,\qquad
\begin{bmatrix}\cos\phi & \sin\phi\end{bmatrix}
\begin{bmatrix}a\\b\end{bmatrix}\approx x(t)
$$

得到该频段的复幅值 $U=a_u-\mathrm{j}b_u$、$Y=a_y-\mathrm{j}b_y$，频响 $H=Y/U$。三次全幅结果做**复数平均**（不是幅值平均，保留相位一致性检验）。

### 3.2 相干函数

以 100 Hz 重采样后用 Welch 法（`nperseg=1024`, `noverlap=512`）计算 $\gamma^2(f)$，再插值到上述频段中心。**仅使用 $\gamma^2>0.8$ 的频点参与拟合**。

### 3.3 参数拟合

以对数复误差为残差、相干为权重：

$$
\min_{K,f_n,\zeta,T_d}\;\sum_i \gamma_i^2\left|\ln\frac{H_i^{\text{meas}}}{H^{\text{model}}(f_i)}\right|^2
$$

实部对应幅值误差（dB），虚部对应相位误差，二者自然同权。

### 3.4 时域验证

用日志中的**真实扫频指令序列**驱动模型（含 100 Hz ZOH 与纯延迟），与总线回传比较 Pearson $r$ 与 VAF：

$$
\mathrm{VAF}=100\left(1-\frac{\mathrm{var}(y-\hat y)}{\mathrm{var}(y)}\right)\%
$$

### 4.3 为什么 log6 是 beta 的主拟合源

其余 beta 日志 `IDEN_CH_F1=30`，在 22 Hz 处相干已塌到 0.3–0.8，19 Hz 以内幅值几乎不掉，导致 $f_n$ 完全不可辨（拟合区间 18–29 Hz 都能给出同样精度）。log6 把 `IDEN_CH_F1` 设为 60，实际扫到幅值触底的 38 Hz，26 Hz 处相干仍有 0.89，首次实测到 $-3$ dB（29.9 Hz），把 $f_n$ 收敛到 24.3–24.6 Hz。

### 4.4 回传质量的历史问题

早期总线回传失败率高达 8–17%（log9 19.1%、log12 8.2%、log13 7.7%）。将 `FsUartServo.cpp` 中的查询超时与控制让路窗口统一改为 3 ms 后：

```
k_high_rate_query_timeout_us = k_query_control_guard_us = 3000
```

扫频段空值降至 0.03–0.4%。**超时必须短于两帧间隙**：100 Hz 发令时帧间隙 10 ms，3 ms 合适；设到 8 ms 会挤掉下一帧控制指令。

### 5.3 延迟的构成

$T_d$ 是 **100 Hz 控制器看到的总延迟**，包含：

- 100 Hz 零阶保持的半拍：5 ms（固定）
- 舵机自身响应延迟 + 总线往返：alpha 约 4 ms，beta 约 10.7 ms

> beta 在 200 Hz 下单独拟合给出总延迟 9.8–12.0 ms，比 100 Hz 的 15.7 ms 少约 5 ms，与半拍 ZOH 一致。

## 七、关于"带宽"的重要说明

### 7.1 现象

$-3$ dB 频点处的实际相位：

| | $-3$ dB 频点 | 总相位 | 其中二阶贡献 | 其中延迟贡献 |
|---|---|---|---|---|
| alpha | 11.9 Hz | $-152^\circ$ | $-113^\circ$ | $-38^\circ$ |
| beta | 28.7 Hz | $-268^\circ$ | $-106^\circ$ | $-163^\circ$ |

beta 更极端：相位在 19.6 Hz 就已过 $-180^\circ$，而此时幅值还是 0 dB。

### 7.2 为什么会这样

两个原因叠加：

1. **二阶系统本身**：$\zeta\approx 0.5\text{--}0.6$ 时，$-3$ dB 处相位约 $-105^\circ \sim -113^\circ$，本来就不在 $-90^\circ$
2. **延迟主导**：beta 在 28.7 Hz 处，15.7 ms 延迟已占 0.45 个周期，单独贡献 $-163^\circ$

$$
\varphi_{\text{delay}}(f)=-360^\circ\cdot f\cdot T_d
$$

### 7.3 结论：不能用 $-3$ dB 带宽衡量动态性能

$-3$ dB 的定义仍然成立（正弦幅值掉到 0.707 的频率），但在该频率上输出是**幅值略小的反相波**，跟踪误差比低频还大。用 $-3$ dB 说"beta 比 alpha 快一倍多"（29 vs 12 Hz）会严重高估可用带宽。

**应改用相位频点**：

| 频点 | 含义 | alpha | beta |
|---|---|---|---|
| $-45^\circ$ | 一阶等效带宽，外环设计依据 | 4.3 Hz | 5.3 Hz |
| $-90^\circ$ | 输出落后 1/4 周期，跟踪上限 | 7.5 Hz | 10.4 Hz |
| $-180^\circ$ | 比例外环稳定边界 | 14.9 Hz | 19.6 Hz |
| $-3$ dB | 仅表示幅值跟踪上限 | 11.9 Hz | 28.7 Hz |

### 7.4 为什么选 $-45^\circ$

一阶惯性 $K/(\tau s+1)$ 的 $-3$ dB 频点与 $-45^\circ$ 频点重合，都是 $1/(2\pi\tau)$。教科书里的"带宽"对一阶而言就是这一点。

本系统因延迟把两点拆开了，此时 $-45^\circ$ 仍保留"一阶等效带宽"的含义，且与外环 1–2 Hz 交叉频率匹配。反推等效时间常数：

$$
\tau=\frac{1}{2\pi f_{-45^\circ}}
$$

- alpha：$\tau=37$ ms，$\quad 0.97/(0.037 s+1)$
- beta：$\tau=30$ ms，$\quad 0.97/(0.030 s+1)$

若按 $-3$ dB 反推，beta 会得到 $\tau=5.5$ ms，在 1.5 Hz 处只有 $-3^\circ$，把延迟造成的相位亏空吃掉，外环裕度会算得偏乐观。

|---|---|---|---|---|---|---|
| 1.0 Hz | $-9.6^\circ$ | $-13.1^\circ$ | $-3.5^\circ$ | $-8.4^\circ$ | $-10.7^\circ$ | $-2.3^\circ$ |
| 1.5 Hz | $-14.4^\circ$ | $-19.2^\circ$ | $-4.8^\circ$ | $-12.6^\circ$ | $-15.8^\circ$ | $-3.2^\circ$ |
| 2.0 Hz | $-19.4^\circ$ | $-24.9^\circ$ | $-5.6^\circ$ | $-16.7^\circ$ | $-20.7^\circ$ | $-3.9^\circ$ |
| 5.0 Hz | $-53.3^\circ$ | $-49.3^\circ$ | $+4.0^\circ$ | $-42.1^\circ$ | $-43.3^\circ$ | $-1.2^\circ$ |

**一阶等效只用于手算裕度，不要放进仿真**。幅值上差别很大：beta 在 5 Hz 处真实 $+0.11$ dB，一阶给 $-2.76$ dB；alpha 在 6 Hz 处差 5.7 dB。

## 八、仿真使用方法

### 8.1 三种等价形式

| 形式 | 适用场合 | alpha | beta |
|---|---|---|---|
| (A) 连续 + 总延迟 | 指令当连续信号 | $T_d=0.009$ | $T_d=0.0157$ |
| (B) ZOH + 连续 + 延迟 | Simulink 前接 ZOH(0.01) | $T_d=0.004$ | $T_d=0.0107$ |
| (C) 100 Hz 离散 | 离散仿真，精确 ZOH 等效 | 见下 | 见下 |

三种在有效频带内 Bode 重合到 $1^\circ$ 以内，**任选一种，不要混用**。

### 8.2 离散模型 (C)

**alpha**（$T_d^{\text{cont}}=4$ ms，不足一拍，纯分数延迟）

$$
H_\alpha(z)=\frac{0.054582 z^{-1}+0.179289 z^{-2}+0.016094 z^{-3}}{1-1.279830 z^{-1}+0.537526 z^{-2}}
$$

$$
y_k=1.279830\,y_{k-1}-0.537526\,y_{k-2}+0.054582\,u_{k-1}+0.179289\,u_{k-2}+0.016094\,u_{k-3}
$$

直流增益 0.97，极点模 0.733。

**beta**（$T_d^{\text{cont}}=10.7$ ms = 1 拍 + 0.7 ms）

$$
H_\beta(z)=\frac{0.526823 z^{-2}+0.357371 z^{-3}+0.000984 z^{-4}}{1-0.255129 z^{-1}+0.167683 z^{-2}}
$$

$$
y_k=0.255129\,y_{k-1}-0.167683\,y_{k-2}+0.526823\,u_{k-2}+0.357371\,u_{k-3}+0.000984\,u_{k-4}
$$

直流增益 0.97，极点模 0.409。

离散系数由状态空间精确离散化得到（含分数延迟增广），已校验：与连续模型在 19 Hz 内相位差 $<1^\circ$，26 Hz 处 $<2.4^\circ$；幅值差为 ZOH 的 sinc 衰减（19 Hz 处 $-0.5$ dB）；阶跃响应差 $<0.02^\circ$。

### 8.3 Simulink 设置

**情况一：外环本身是 100 Hz 离散（推荐，最贴近实机）**

用 `Discrete Transfer Fcn`，Sample time = 0.01，**前面不要加 ZOH 或 Transport Delay**（延迟已含在系数里）：

| | Numerator | Denominator |
|---|---|---|
| alpha | `[0 0.054582 0.179289 0.016094]` | `[1 -1.279830 0.537526 0]` |
| beta | `[0 0 0.526823 0.357371 0.000984]` | `[1 -0.255129 0.167683 0 0]` |

**情况二：连续仿真，指令按 100 Hz 保持**

`Zero-Order Hold`(0.01) $\to$ `Transfer Fcn` $\to$ `Transport Delay`

| | 分子 | 分母 | Transport Delay |
|---|---|---|---|
| alpha | `0.97*3563` | `[1 62.1 3563]` | **0.004** |
| beta | `0.97*23697` | `[1 178.6 23697]` | **0.0107** |

延迟减掉 5 ms，因为那半拍由 ZOH 模块自己产生。

**情况三：纯连续**

同上但去掉 ZOH，Transport Delay 改为 alpha `0.009`、beta `0.0157`。

### 8.4 非线性补充

模型输出后串 `Rate Limiter`：

- alpha：$\pm 555$ °/s
- beta：$\pm 600$ °/s

小信号仿真不受影响。大幅阶跃时必须加：$\pm 15^\circ$ 阶跃下 beta 的线性模型需要 1137 °/s 峰值速率，接近实测上限的两倍，不加会让模型明显快于实物（详见第九节）。

### 8.5 MATLAB 代码

```matlab
s = tf('s');  Ts = 0.01;
% alpha
Ga_c = 0.97*3563/(s^2 + 62.1*s + 3563);
Ha_c = Ga_c * exp(-0.009*s);
Ha_d = tf([0 0.054582 0.179289 0.016094], [1 -1.279830 0.537526 0], Ts);
% beta
Gb_c = 0.97*23697/(s^2 + 178.6*s + 23697);
Hb_c = Gb_c * exp(-0.0157*s);
Hb_d = tf([0 0 0.526823 0.357371 0.000984], [1 -0.255129 0.167683 0 0], Ts);
```

### 8.6 Python 代码

```python
import numpy as np
from scipy.signal import dlti, dlsim
Ts = 0.01
alpha_d = dlti([0.054582, 0.179289, 0.016094], [1, -1.279830, 0.537526, 0], dt=Ts)
beta_d  = dlti([0.526823, 0.357371, 0.000984], [1, -0.255129, 0.167683, 0, 0], dt=Ts)

```

### 8.7 外环设计建议

上述 $H(s)$ 已是舵机闭环，在仿真中作为**被控对象**。外环再包一层，整个系统闭环为 $L/(1+L)$，其中 $L=C(s)H(s)$。

**交叉频率建议 1–2 Hz**。此时对象相位仅 alpha $-14.4^\circ$、beta $-12.6^\circ$（@1.5 Hz），幅值仍为 0 dB，相位裕度基本由控制器决定。

## 十、200 Hz 发令的情况

如果控制器改为 200 Hz，模型需要重测，不能简单套用。

| | 100 Hz $-45^\circ$ | 200 Hz $-45^\circ$ | 100 Hz $T_d$ | 200 Hz $T_d$ |
|---|---|---|---|---|
| alpha | 4.5–4.7 Hz | 5.6 Hz（log12） | 9 ms | 约 3–4 ms(*) |
| beta | 5.2–5.3 Hz | 6.1–7.2 Hz（log5/log13） | 15.7 ms | 约 10–12 ms |

(*) 200 Hz 时 ZOH 半拍为 2.5 ms，减少量不止半拍，说明总线查询周期缩短本身也降低了延迟。

beta 在 200 Hz 下的可用模型（若确需）：

$$
H_\beta^{200}(s)=0.97\cdot\frac{19108}{s^{2}+168.6\,s+19108}\cdot e^{-0.010 s}
$$

仿真已做 200 Hz ZOH 时连续延迟用 7.5 ms。

## 十一、复测指引

若需重新辨识：

1. QGC 参数页搜 `IDEN`，按第 2.1 节设置；`FS_UT_1WIRE`、`FS_UT_BAUD` 改后需重启飞控
2. 确认 `RC_MAP_AUX1` 已映射
3. **建议 `IDEN_CH_F1` 设为 60**（不是 30），让扫频跑到幅值触底，才能测到 $-3$ dB 与真实 $f_n$
4. 飞控**不要**绑在舵臂上（用总线回传更准），但要放稳，避免阶跃时陀螺尖峰超过 30 °/s 触发误判
5. 模式用 Manual / Stabilized / Acro，解锁后 AUX1 拉过 `IDEN_AUX_THR`
6. 一次只测一个通道；换通道需上锁 $\to$ 改 `IDEN_SV_IDX` $\to$ 再解锁
7. 测完把 `IDEN_TYPE` 改回 0
