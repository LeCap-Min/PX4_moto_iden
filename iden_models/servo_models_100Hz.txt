================================================================================
FashionStar 总线舵机 闭环传函（用于 100 Hz 控制器仿真）
alpha / beta 两台舵机  ·  指令角(deg) → 总线回传角(deg)
数据：2026-08-27 台架扫频，100 Hz 发令/查询，0.2~30 Hz 对数扫频 ×3 + 半幅
================================================================================

【适用条件】
  - 控制器以 100 Hz 发角度指令，回读同为 100 Hz。总延迟已含 100 Hz 零阶保持半拍 (5 ms)。
  - 小信号线性模型：指令角速度不超过 Vmax 时有效。大幅阶跃会被速率限制，此时模型偏快。
  - 有效频带：alpha ≤ 12 Hz，beta ≤ 26 Hz。带外只保证趋势。
  - 单位：角度 deg，时间 s，s 为拉普拉斯变量，z 为 100 Hz 离散算子。

--------------------------------------------------------------------------------
一、alpha 舵机（总线 ID 1 / 3）
--------------------------------------------------------------------------------
参数：K = 0.97   fn = 9.5 Hz   zeta = 0.52   td_total = 9 ms   Vmax ≈ 555 deg/s

  wn = 2*pi*9.5 = 59.69 rad/s
  wn^2 = 3563     2*zeta*wn = 62.1

(A) 连续模型（输入视作连续信号时用，含全部延迟）
    H(s) = 0.97 * 3563 / (s^2 + 62.1*s + 3563) * exp(-0.009*s)

(B) 连续模型 + 100 Hz ZOH（Simulink：ZOH(0.01) → 传函 → Transport Delay）
    G(s) = 0.97 * 3563 / (s^2 + 62.1*s + 3563)
    Transport Delay = 0.004 s              （9 ms 减去 ZOH 半拍 5 ms）

(C) 100 Hz 离散模型（精确 ZOH 等效，含 4 ms 分数延迟；直接用于离散仿真）
    H(z) = (0.054582 z^-1 + 0.179289 z^-2 + 0.016094 z^-3)
           / (1 - 1.279830 z^-1 + 0.537526 z^-2)
    差分方程：
    y[k] = 1.279830*y[k-1] - 0.537526*y[k-2]
           + 0.054582*u[k-1] + 0.179289*u[k-2] + 0.016094*u[k-3]
    直流增益 0.97，极点模 0.733

模型特征：-45° 4.3 Hz，-90° 7.5 Hz，-3 dB 11.9 Hz
外环设计用的一阶近似：0.97 / (0.037*s + 1)，交叉 1.0~1.6 Hz 时够用

--------------------------------------------------------------------------------
二、beta 舵机（总线 ID 5 / 7）
--------------------------------------------------------------------------------
参数：K = 0.97   fn = 24.5 Hz   zeta = 0.58   td_total = 15.7 ms   Vmax ≈ 600 deg/s
      （fn/zeta 由 log6 扫到 38 Hz 的实测定出，此前 30 Hz 截断只能外推；
        200 Hz 查询斜率法测得 Vmax≈800，取 600 偏保守）

  wn = 2*pi*24.5 = 153.94 rad/s
  wn^2 = 23697    2*zeta*wn = 178.6

(A) 连续模型（含全部延迟）
    H(s) = 0.97 * 23697 / (s^2 + 178.6*s + 23697) * exp(-0.0157*s)

(B) 连续模型 + 100 Hz ZOH
    G(s) = 0.97 * 23697 / (s^2 + 178.6*s + 23697)
    Transport Delay = 0.0107 s             （15.7 ms 减去 ZOH 半拍 5 ms）

(C) 100 Hz 离散模型（精确 ZOH 等效，含 10.7 ms = 1 拍 + 0.7 ms 分数延迟）
    H(z) = (0.526823 z^-2 + 0.357371 z^-3 + 0.000984 z^-4)
           / (1 - 0.255129 z^-1 + 0.167683 z^-2)
    差分方程：
    y[k] = 0.255129*y[k-1] - 0.167683*y[k-2]
           + 0.526823*u[k-2] + 0.357371*u[k-3] + 0.000984*u[k-4]
    直流增益 0.97，极点模 0.409

模型特征：-45° 5.3 Hz，-90° 10.4 Hz，-3 dB 28.7 Hz（log6 实测 29.9 Hz）
外环设计用的一阶近似：0.97 / (0.030*s + 1)，交叉 1.2~1.8 Hz 时够用

--------------------------------------------------------------------------------
三、MATLAB 直接粘贴
--------------------------------------------------------------------------------
s = tf('s');  Ts = 0.01;
% alpha
Ga_c  = 0.97*3563/(s^2 + 62.1*s + 3563);                 % 连续部分
Ha_c  = Ga_c * exp(-0.009*s);                             % 连续 + 总延迟 (A)
Ha_d  = tf([0 0.054582 0.179289 0.016094], [1 -1.279830 0.537526 0], Ts);  % 离散 (C)
% beta
Gb_c  = 0.97*23697/(s^2 + 178.6*s + 23697);
Hb_c  = Gb_c * exp(-0.0157*s);
Hb_d  = tf([0 0 0.526823 0.357371 0.000984], [1 -0.255129 0.167683 0 0], Ts);
% 校验：bode(Ha_c, Ha_d) 到 19 Hz 相位重合（<1°），幅值差 <0.5 dB（ZOH 的 sinc 衰减）
% Simulink 用 (B)：Zero-Order Hold(0.01) -> Transfer Fcn G -> Transport Delay(0.004 / 0.0107)

五、大信号补充（可选）

若仿真中会出现大幅阶跃，请在模型输出后加速率限幅：
  alpha  |dy/dt| ≤ 555 deg/s
  beta   |dy/dt| ≤ 600 deg/s

六、置信度（交叉验证结果）
--------------------------------------------------------------------------------
alpha（拟合日志 log15/16/17 ch3、log2 ch1，均 100 Hz）
  留一法：任取 3 份拟合、预测第 4 份，fn 9.0~9.3 Hz，zeta 0.47~0.48，td 8.2~9.4 ms，
          幅值预测误差 ≤1.2 dB，相位 rms 3.3~5.4°（≤12 Hz）
  时域：用实际扫频指令驱动模型，与总线回传比，VAF 98.4~99.3%，残差 rms 0.5~0.6°（信号 rms 5.4°）
  跨通道：ch1 与 ch3 的 -45°/-90° 频点差 <0.2 Hz
  独立 200 Hz 日志 log12：总延迟减 5 ms 后相位 rms 4.4°，偏差 +1.1°

beta（fn/zeta/td 取自 log6 ch5：F1=60、扫到 38 Hz，26 Hz 内相干 ≥0.87，是唯一能定 fn 的日志；
      再用 log18 ch7、log0/log3/log4 ch5 复核，均 100 Hz）
  log6 单独拟合（≤25/30 Hz）：fn 24.3~24.6 Hz，zeta 0.57~0.59，td 15.6~15.8 ms；
        实测 -3 dB 29.9 Hz，-45° 5.24 Hz，-90° 10.44 Hz
  对五份日志的误差（≤19 Hz，log6 ≤26 Hz）：
        log18 0.62 dB / 1.7°   log0 0.34 dB / 1.3°   log3 0.34 dB / 1.6°
        log6  0.35 dB / 2.2°   log4 1.59 dB / 7.4°（飞控绑臂上、用陀螺，偏差最大）
  时域：VAF 98.2~99.4%，残差 rms 0.4~0.6°（信号 rms 5.2°）
  跨通道：ch5 与 ch7 的 -45° 差 <0.1 Hz，-90° 差 <0.2 Hz
  独立 200 Hz 日志 log13/log5：总延迟减 5 ms 后相位 rms 5.4°/2.6°
  注意：只到 19 Hz 的日志合并拟合会给 fn≈21.6，因为该段幅值几乎不掉、对 fn 不敏感；
        两组参数在 19 Hz 内相差 <1 dB / 3°，对 1~2 Hz 交叉的外环仿真没有影响
  半幅（4°）扫频低频增益 0.92 vs 全幅 0.97，对应约 0.2° 死区/回差，仿真可忽略

结论：两模型在各自有效频带内幅值误差 ≤1.2 dB（log4 除外）、相位误差 rms ≤6°、时域 VAF ≥98%，
      可直接用于 100 Hz 外环算法仿真。
